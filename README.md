# Executive Overview Dashboard (Tableau)

## Project Overview

This project presents an interactive Tableau dashboard built using the Sample Superstore dataset.

The dashboard provides executive-level insights into:

- Sales Performance
- Profitability
- Customer Segments
- Geographic Trends
- Regional Performance

## Key Performance Indicators

The dashboard tracks:

- Total Sales
- Total Profit
- Profit Ratio
- Profit per Order
- Sales per Customer
- Average Discount
- Quantity Sold
- Count of Orders

---

## Features

- Interactive Date Filters
- Region Filters
- Geographic Mapping
- Category Analysis
- Customer Segment Analysis
- Executive KPI Cards
- Dynamic Dashboard Interactions
